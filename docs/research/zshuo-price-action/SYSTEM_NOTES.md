## 1. 体系总览

- 流派：Al Brooks 价格行为改良（自认师承"阿布爷爷"，多处主动引用；与 Brooks 11C 微缺口/实体缺口有重叠但不等同，"突破型缺口/信号K缺口"为其自创命名）。
- 品种/周期：NQ/ES/GC 期货，日内+小波段；1/5min 执行，1H/4H 定背景；唯一指标 EMA20（可关）；**只用 stop 单进场，不用限价单**（"限价成交那一刻你是逆势方，stop 触发那一刻你是顺势方"）。
- 三层结构，优先级自上而下：

```
背景（趋势/震荡判定）      ← "背景是价格行为的核心，缺口是背景的核心"
  └ 支撑阻力（位置）        ← 唯一底层机制：被套者有打平离场的真实需求
      └ 形态/信号K（扳机）  ← Setup = ≥1 个 S/R + ≥1 个形态；总理由 ≥2 个叠加
```

## 2. 背景判定（前置硬流程）

二元决策：趋势 or 震荡 → 若趋势，再分三档：

| 背景 | 强度 | 打法 |
|---|---|---|
| 突破 | 强 | 只顺势 |
| 窄通道 | 强 | 只顺势 |
| 宽通道 | 弱趋势 | 双向可做，尽量顺势（逆势方一直能赚钱=阶梯模式） |
| 震荡区间 | — | 顶底高抛低吸、押注突破失败；**三禁**：不押注突破、不在中间进场、止损不贴边界 |

### 2.1 "缺口行为"三判据（他自创命名）

1. **能否制造缺口**（顺势方视角）：能造且长时间敞开 → 突破阶段，60% 概率到 MM；造出即被回补 → 假突破/弱趋势/震荡。
2. **能否回补缺口**（逆势方视角）：能回补 → 弱趋势、阶梯模式、趋向震荡；无法回补 → 顺势方极强。
3. **能否回补实体缺口**：逆势方在趋势中能拿到的**极限 = 回补实体缺口**；连实体缺口都补完还没恢复趋势 → 警惕反转或已入震荡。

**"缺口无效"的二义判据**（原话重复 4 次）：缺口未起 S/R 作用、被反向实体直接回补 → 要么制造缺口方是大趋势的逆势方，要么在震荡区间。一般是后者。

### 2.2 stop 盈亏判据

- 逆势方 stop 很难赚钱 → 强趋势，只顺势。
- 逆势方 stop 能赚钱 → 回调深、阶梯模式、弱趋势。
- 双方 stop 都赚不到钱、好趋势K无好跟随 → 一定在震荡区间。

### 2.3 趋势强度 5 证据 / 震荡 6 特征（视频 5 清单）

趋势强度：① 高低点结构（单看不够，要看是否突破左侧波段高低点+制造缺口）② 缺口敞开程度 ③ 回调时长/幅度（**>20 根 K 或回调 >60–70% → 趋近震荡**，好趋势回调浅）④ 逆势趋势K不应有好跟随 ⑤ 顺势趋势K应实体饱满、影线少（频繁外包/内包/OO/铁丝网 → 末端旗形或 TTR）。

震荡特征：① 同时具备双向趋势特征（扩张三角=震荡）② 频繁十字星/长影线/逆势方赚钱/缺口一直被回补 ③ 新高新低幅度递减（10点→5点→2点）④ 小概率事件频繁发生（坏信号K的人也能赚钱）⑤ 缺口无效（见 2.1）⑥ 无论几次突破失败，默认继续震荡。

### 2.4 心法层

- 80% 法则：趋势中 80% 的反转是小反转；区间中 80% 的突破会失败。
- "10% 结构 + 90% 信念"：趋势中 10% 恢复结构 + 90% 对延续的信念；区间中 10% 反转结构 + 90% 对区间持续的信念。
- **信念感 ≠ 扛单**（本人专门澄清）：只是让你在正常回调/区间试探突破时不恐慌离场，改变发生时必须反应。

## 3. 缺口子体系（核心）

### 3.1 定义

**不是跳空**。缺口 = 被实体K突破的波段高/低点，画成一条水平线 = **被套者的成本价**。多头被套 → 涨回来时是阻力；空头被套 → 跌回来时是支撑。"回补缺口" = 价格回到该线、被套者打平离场。

### 3.2 分类

| 类型 | 定义 | 使用度 |
|---|---|---|
| 突破型缺口 | 解套需求（真实供需），主用 | ★★★ |
| 信号K缺口 | 原入场方再次进场/打保本损；**无解套需求** | ★（本人很少用） |
| 微缺口 / 实体缺口 | Brooks 11C 概念；实体缺口=只看线形图的机构被套 | 背景判断用 |
| 测量型缺口 | 突破后回调未回补 → 60% 概率到 MM | 目标测量用 |
| 竭尽型缺口 | 与测量型的判别靠"抛售高潮概率"权衡 | 裁量 |

### 3.3 画线规则

- 锚点K线四类：光头阴线→**最高点(=开盘价)**；光脚阳线→**最低点(=开盘价)**；长下影阳线→影线低点；长上影阴线→影线高点。非封闭清单（"还有一些类型"）。
- **为何锚在开盘价端**（本人评论区答疑，唯一权威解释）：大趋势K是机构从开盘就开始买/卖才造出来的——若所有人都等好信号K用 stop 进场，趋势K是谁造的？
- **实体 vs 影线 tie-breaker**（本人答疑）："大体积K看实体，影线占比大的K看影线，不过对颜色有一定要求"——**"颜色要求"未在任何文字材料展开，必须看《缺口一》原片**。
- 成立条件：**实体突破即成立，跟随非必要**（"并不是说非要有跟随"）；跟随是强度变量——让被套方意识到被套，"被套无法回补的时间越长，越想打平而不是赚钱"。⚠️ forecho 把跟随写成了硬条件，是转述错误。

### 3.4 失效规则（本人答疑，forecho 完全没写）

- **任何缺口被回补过即失效**；缺口一次性，用过即删。
- 跨周期例外：5min 回补但 15m/30m/1H 未回补 → 仍有效，甚至更有效。
- 已回补的缺口后来"又有效" → 大概率实为与第一次回补位形成的双顶/双底。

### 3.5 与 MM 的绑定

测量型缺口 60% 概率到 measure move；**投影基准 = 制造缺口那段腿的高/低点翻倍**（⚠️ forecho 写成"从缺口投影"，基准点错误）。实测精度示例：MM 投影 18283.5，实际低点 18284（差 2 tick）；AB=CD 投影 4593.4，实际高点 4593.5。

## 4. 支撑阻力清单

**静态**（可提前画，每日开盘前先画昨日/上周关键位——他的固定开盘动作）：前高前低｜前高前低的**收盘价**（买好趋势K收盘被套者，成本整齐，常比波段点更灵敏）｜昨日/上周高低点｜趋势线/通道线（通道线被实体破 → MTR 温床）｜50% 回调（1:1 盈亏比 × 约60% 顺势胜率 = +0.2 期望）｜趋势/通道起点（最激烈；下跌趋势起点被实体突破+跟随 ≈ MTR 信号）｜**缺口**（"我体系中最重要的 S/R"）｜GEX（期权，未展开）。

**动态**：MM / AB=CD（约60%，市场惯性而非被套逻辑）｜EMA20（近20根K的短线平均成本）｜VWAP（当日量加权成本，机构在意）。

**形态/扳机**（开放式清单）：三推楔形及变体｜失败类（二次突破失败/MTR/MTRS）｜多次回补缺口失败｜三角形突破｜牛熊旗及其反向突破｜II/OO/IOI（breaker mode）｜两段式陷阱（诱多诱空）｜微型双顶双底｜D1/D2/G1/G2｜AIL｜抛售/抢购高潮。
信号K质量：好 = 内包、实体饱满、收在极值、影线短；坏 = 外包、长影线、振幅过大（叠加位再好也放弃）。

## 5. 具名入场 Setup（四元组）

止损列大量空缺是材料的真实状态，不是整理遗漏——见 §9。

| Setup | 触发 | 入场 | 止损 | 目标 |
|---|---|---|---|---|
| **二次回补缺口失败**（签名 setup） | 缺口留下 → 两次回补失败（差一点够不到成本线）形成双顶/底 → 顺势好信号K | 信号K stop | 未给 | 测量型缺口 MM，"盈亏比≥2" |
| **差一点没补完缺口**（自称最爱） | "能补完他一定会补完，差一点=多头抢跑、真不愿再补" + 通道线 + 前高 | stop | 结构上方（明确） | 下方缺口回补位 |
| 多次回补失败顺势 | 多次尝试回补失败/力竭市价跑路 | 制造缺口方向好信号K | 未给 | 顺势 MM |
| 叠加位反转 | ≥2–4 个 S/R 叠加（缺口+通道线+趋势线+AB=CD 等）+ 好信号K（内包阴/阳线收极值） | 信号K | 未给 | 区间对沿 / MM |
| 震荡区间高抛低吸 | 确认边界（"两腿后基本确定"）；上 1/3 只空、下 1/3 只多、**中间一律不做** | ≥2 理由 + 信号K | **宽止损**（放区间高点/大缺口位，唯一成体系的止损原则） | 对侧边界 |
| AIL 回调二次入场 | 超大阳线 AIL 后不追突破 | 等小回调+双底+内包K光脚阳 | 未给 | 两根K高度 MM / 前高翻倍 |
| 双向 stop 陷阱 | II/内包K 先向下诱空一个 tick 收回 | 反方向高点挂 stop | 未给 | 未给 |
| MTR（视频1 精确定义） | 两个条件：① 跌破趋势线/上涨通道趋势线 ② 制造出 EMA20 均线缺口；回测通道起点 | 空头信号K | "放在区间外面是合理的" | 未给；大反转 MTR 须先等逆势方到 measure move 目标位（视频7） |
| M2S / M2B（视频1 补全） | Brooks 高二/低二回调到 EMA20 附近：M2B = 上涨趋势高二回调至 EMA；M2S = 下跌趋势低二（两段式反弹）至 EMA | M2S 等 D2 信号K做空 / M2B 等 G2 信号K做多 | 未给 | 未给 |
| 大周期缺口+小周期入场（评论区 29 赞归纳） | 1H 缺口 + 5min 两次回补失败 + 好信号K | 5min 信号K | 5min 信号K 止损 | 1H 波段（盈亏比高、机会少） |

**持仓/离场**：目标以 MM 为先，"无论如何应倾向拿到 MM 才止盈"；多目标位取**最近**的；顺势单必须尽量拿到目标位；提前离场唯一例外 = 逆势方出现连续大K。

## 6. 禁止规则（他的"不做"清单，最接近机械化的部分）

1. 震荡区间中间不进场（全库最高频规则）
2. 区间不押注突破，宁愿反转被止损也不押突破；突破了别追高，等回调/旗形
3. TTR（窄幅震荡）不操作
4. 信号K为外包K/长影线 → 放弃
5. 连续 ≥4 根逆势K → 至少等二次入场
6. 已到 MM 位置不追
7. K线振幅过大 / 止损需放太宽 → 不做
8. 大新闻大K → 全部删线等待
9. **新手不加仓**（"加仓会导致新手期望值大幅降低"，含反对加仓摊平）
10. 不用限价单
11. 强趋势+持续测量型缺口 → 不摸底（"底只有一个，你摸不到"）
12. 做反转前必须确认顺势方已到目标位（视频7 评论区归纳）

## 7. 训练方法（他自述的路径）

- 每天复盘画图，"前两年复盘了几千张图"，期间 prop firm "一直亏、一直炸号、一直爆仓"，后期才顺。

- 提前画线是复盘的核心动作："你连复盘都看不出来的东西，实盘更不可能看出来。"

### 8.2 视频 6《交易逻辑》（[06-trading-logic.md](transcripts/06-trading-logic.md)）——止损方法论的主要出处
三段框架：止损设置 / 目标位测量 / 趋势恢复逻辑。

**止损核心原则："止损必须与入场逻辑完全匹配，做到知行合一。"**
- 认为"回调后 60% 概率恢复趋势" → 止损放**趋势起点 / 前一重要波段低点 / 结构失效位**（给正常波动留空间）；放信号K最低点 = 宣称"进场即须立刻恢复、不允许任何回调"——逻辑冲突，会被正常回调打掉。
- **窄止损唯一合法条件**："只有当你认为跌破信号K低点趋势就不复存在、前提失效时，才能设窄止损。"他本人的窄止损场景：回补完缺口后出现恢复趋势信号（此时再回调破该K极值 = 前提失效）。
- 反推法：设好止损后倒推"我真正表达的意思是什么"，检查与观点是否矛盾（追涨+信号K低点止损 = 典型知行不一）。

**目标位测量由近及远六档**：实体AB=CD → 影线AB=CD → 被突破前波段高低点测实体MM → 测影线MM → 单腿回调波段测实体MM → 测影线MM。他常用影线AB=CD + 后四种。

**趋势恢复逻辑**："回调本质是顺逆双方争夺目标位并保护趋势结构的过程；逆势方能否制造缺口，决定顺势方恢复趋势的代价。""**真正的拐点很可能不是叠加最多的位置，而是逆势方达到目标位之后、优势开始衰竭的位置。**"自陈"我现在的体系 80–90% 都和缺口相关"。

### 8.3 视频 7《缺口+杂谈（三）》（[07-gap-part3.md](transcripts/07-gap-part3.md)）
- 市场行为只有三种目的：突破成功套住对方 / 到目标位 / 解套。被套两类：赌突破失败被套（→缺口）、赌突破成功被套（→好趋势K收盘价/stop位）。
- **两种最有效的缺口**：①"精准MM缺口"——测量位引发最强反应者，代表最强机构，其止盈造成回调、日后价格会回其原入场位；②"最后一个缺口"——引导该段趋势启动的机构所在。
- HL-MTR / LH-MTR（高点降低/低点抬高的MTR）：成因是缺口阻挡了对极值的回测。
- **离场三方式（唯一许可清单）**：坚定持有到目标位止盈｜对手方强势反转且**出现 MTR + 好信号K**再离场｜耐心等初始止损被触发。"没有扛单这种说法——背景判断准确就不该触发合理止损；触发了说明判断错了。"禁止亏点就跑。
- 震荡区间止损宽度上限：**区间高低点高度翻倍的 MM 位置**。逆势/窄通道反转只能放信号K高点的窄止损 → "尽可能不要做"。
- 仓位哲学："仓位足够小，用不在乎的钱交易"——解决的不是技术判断问题，而是身份定义问题：用在乎的钱你就是利益相关方，天然偏袒自己的持仓方向。

## 9. 体系弱点与可回测性评估
