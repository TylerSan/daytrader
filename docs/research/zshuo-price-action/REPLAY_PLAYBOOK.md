## 1. 盘前流程（replay 起点日，开始逐K前完成）

按顺序画完才允许按播放：

1. 昨日高/低、上周高/低。
2. **缺口扫描**（往左至少 200 根K）：找被实体K突破的波段高/低点，锚点规则：
   - 光头阴线 → 最高点；光脚阳线 → 最低点；长影线K → 影线极值；
   - 大体积K看实体、影线占比大看影线（颜色细则未考证，`[补全]` 默认：只对"锚点K与突破K异色"的组合画线）;
   - **已被回补的缺口一律删除**（跨周期例外：5min 补了但 15m/30m/1H 敞开 → 保留并标"跨周期"）。
3. 趋势线、通道线（含前置通道）。
4. 最近一段主要腿的 50% 回调位、趋势/通道起点。
5. 未回补缺口的 MM 投影（基准 = 制造缺口那段腿的高/低点翻倍）、成型中的 AB=CD 投影。
6. 大趋势K的开盘价/收盘价水平线（若在当前价 ±1 日波幅内）。

> 原则："不要怕画得乱，要多画。临时找线是找不到的。"

## 2. 背景判定（每次进场前的第一道门，输出必须落笔）

依次回答三组问题，写进 journal 的 `background` 字段：

**Q1 缺口行为**：最近 20–50 根K内，哪一方能制造缺口？造出后敞开还是立刻被回补？实体缺口是否被回补完？
**Q2 stop 盈亏**：最近逆势方用 stop 进场能否赚钱？双方 stop 都赚不到钱吗？
**Q3 回调结构**：当前回调是否 >20 根K 或 >60–70% 幅度？新高/新低幅度是否递减？

判定输出（五选一，写明依据）：

| 判定 | 依据组合 | 允许动作 |
|---|---|---|
| 突破/窄通道 | 持续造缺口+敞开；逆势 stop 赚不到钱 | **只顺势**；回调浅，等二次入场 |
| 宽通道（弱趋势） | 缺口被回补但趋势延续；逆势限价能赚钱 | 双向可做，优先顺势；逆势必须等顺势方到目标位 |
| 震荡区间 | 缺口来回补+测试波段高低点；双方 stop 都难赚钱；小概率事件频发 | 只做顶/底 1/3 反转；**中间禁区** |
| TTR | 窄幅粘连、频繁十字星 | **不做** |
| 不确定 | 判据冲突 | **不做**，继续观察 |

`[补全]` 判定冻结规则：背景判定每次进场前重做，但**持仓中不得因背景改判而改单**（只按止损/目标执行）。

## 3. 位置门：只在预画线处做单

- 价格必须**触碰盘前画好的线并做出反应**（信号K/小双底/收回实体）才进入下一步。"画线是预测，反应才是证据。"
- 临时看出来的位置不算数（盘前没画 = 放弃该机会，记入 journal 的 `missed` 而非补画）。`[补全]` 此条为反事后偏差的硬化。
- **叠加计数**：列出该位置的全部理由，达标线 = **≥2 且至少 1 个 S/R + 1 个形态**。理由白名单（防组合爆炸，`[补全]` 收窄为封闭清单）：
  - S/R（7 项）：缺口｜前高低｜大趋势K开盘/收盘价｜昨日/上周高低｜趋势/通道线｜50%回调｜趋势起点。AB=CD/MM 投影命中算第 8 项。
  - 形态（9 项）：二次回补缺口失败｜差一点没补完｜多次回补失败｜微型双顶/双底｜三推楔形｜MTR（定义：跌破趋势线 + 制造 EMA20 均线缺口，大反转须先等逆势方到 MM 目标位）｜M2S/M2B（H2/L2 回调至 EMA20 + D2/G2 信号K）｜两段式陷阱｜II/内包K。
  - 白名单之外的理由不计数（可记录观察，不得作为进场依据）。

## 4. 扳机门：信号K质检（一票否决）

| 通过 | 否决 |
|---|---|
| 内包K / 实体饱满 / 收在极值端 / 影线短 | 外包K｜上或下影线 > 实体｜振幅显著过大（`[补全]` >2× 近20根K均振幅）｜十字星 |

否决即放弃，无论叠加多好（原话规则）。

## 5. 禁止清单（进场前逐条过，任一命中 = 放弃）

1. 背景判定为 TTR 或"不确定"
2. 震荡区间中间 1/3
3. 押注区间突破（含在边界外挂顺破单）
4. 已到 MM 目标位还追顺势
5. 连续 ≥4 根逆势K后的第一反转（至少等二次入场）
6. 微通道突破后的**首次**反转
7. 止损距离过大：所需止损 > 1.5× 平均真实波幅（`[补全]` 他只说"止损太大不做"，取 ATR(20) 的 1.5 倍为量化线）
8. 大新闻/异常大K后 10 根K内（原话"删线等待"，`[补全]` 量化为 10 根）
9. 逆势单但顺势方未到任何目标位
10. 当日已 3 笔或已 -2R
11. 逆势/窄通道反转且止损只能放信号K极值（窄损逆势单，视频 7："尽可能不要做"）
12. 窄止损但"跌破信号K极值=前提失效"不成立（知行合一检查未通过）

## 6. 入场与止损

**入场**：信号K极值 ±1 tick 挂 stop；未触发且下一根K收盘破坏结构 → 撤单。

**止损**（v0.2 起为视频 6/7 原话方法论，替换 v0.1 的外推默认）：

核心原则：**止损必须与入场逻辑完全匹配（知行合一）**。挂单前反推一句："这个止损位真正表达的观点是什么？"与进场理由矛盾 → 换止损位或放弃。

| 场景 | 止损位 |
|---|---|
| 趋势回调入场（认为趋势会恢复） | **趋势起点 / 前一重要波段低(高)点 / 结构失效位**——给正常波动留空间；放信号K极值 = 知行不一，禁止 |
| 窄止损（信号K极值外 1 tick） | **仅当"跌破信号K极值 = 前提失效"成立时允许**。他的典型场景：回补完缺口后的恢复趋势信号 |
| 震荡区间反转单 | 宽止损，上限 = **区间高低点高度翻倍的 MM 位置**；**禁止**恰好放在区间边界外一点点 |
| 逆势/窄通道反转（只能放信号K高点的窄损） | "尽可能不要做" → 归入 §5 禁止清单 |
| 保本损 | **不移保本**。离场只有三方式（见 §7），"耐心等待初始止损被触发"是其中之一；保本损是"信号K缺口"的猎杀对象 |

## 7. 目标与持仓

1. 主目标：**最近的**一个目标位。目标位测量由近及远六档（视频 6）：实体AB=CD → 影线AB=CD → 被突破前波段测实体MM → 测影线MM → 单腿回调波段测实体MM → 测影线MM。到主目标 → 全平（`[补全]` 1 手无法分批，不留 runner，保持统计干净）。
2. **离场只有三方式**（视频 7 原话，封闭清单）：① 坚定持有到目标位止盈；② 对手方强势反转且**出现 MTR + 好信号K**才离场（MTR 未出现不算）；③ 耐心等待初始止损被触发。
3. "没有扛单这种说法"——背景判断准确就不该触发合理止损，触发了 = 判断错了，记 journal 复盘背景判定，**禁止亏点就跑**。跟随不好但止损是宽止损设计 → 不动。
4. 禁止：加仓、摊平、移保本、盘中改目标改止损。
